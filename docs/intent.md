3. Torn Forum Command Center
Replace Torn’s tiny subscribed-thread box with a proper mobile workspace:
Full-page subscribed-thread view.
Folders, tags and pinned threads.
Read/unread tracking.
Sort by last activity, author, forum or custom priority.
“Catch up from my last visit.”
Locally saved reply drafts.
Search within previously visited subscribed threads.
Separate watchlists for guides, faction discussions and script releases.
The request for a full subscribed-thread organizer received three positive votes and specifically criticized the current small sidebar box in the tool-request discussion. The closest Greasy Fork result I found merely increases the height of existing forum feeds; it does not create a real subscription manager.
The script must remain rules-compliant: it should organize information from the currently viewed page and locally captured visits, rather than crawling forum pages in the background.
Why build it: extremely low data maintenance, almost no serious competition, and a clean PDA-first project.
