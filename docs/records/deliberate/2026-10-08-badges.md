# Deliberation: badges (#9)

- **Subject:** `docs/superpowers/specs/2026-10-08-badges-design.md` at commit `4d21f01` (the first draft spec, 25 badges, banked rest days, local 04:00 day).
- **Rounds:** 2. Round 1 was the independent positions. Round 2 was targeted: six contested points, one ruling each.
- **Executor:** Codex (`codex exec -`, the spec inlined via stdin). It is an independent model family and cannot read files, so the full spec, the owner brief and the repo constraints were pasted in.
- **Model:** `gpt-5.6-sol`, medium effort, for all three seats. The topic is design-shaped.
- **Real cost:** about 282k Codex tokens. Native 83.6k + 78.8k, veteran 28.4k + 32.3k, aesthete 27.5k + 30.9k.
- **Seats:** native (this repo's rules), veteran (what keeps working), aesthete (the best user experience).
- **Owner decision:** "Reduced, TCT day", approved 2026-10-08.

## Resolutions

| # | Point | Votes | Resolution |
|---|---|---|---|
| 1 | Display | 3-0 | One trophy chip after the title, opening a shelf. Not an inline strip, not a second header line. |
| 2 | Streak semantics | 3-0 | Strict consecutive days. No rest-day bank or repair. Best-ever is kept forever. A "12-day streak" bridged across missed days was called dishonest by every seat. |
| 3 | Hidden badges | 3-0 | None. The owner asked for Settings to show every badge and how to earn it. |
| 4 | Catalogue size | 12 / 13 / 17 | 15. The chair split the difference. |
| 5 | Streak ladder | 2-1 for a 3-day early win | 3 / 10 / 25 / 100 / 500, and 7 is dropped. Native wanted the owner's four only. |
| 6 | Forum breadth | 2-1 for a ladder | Three forums-explored badges, for the owner's "reading so many forums". |
| 7 | Reading evidence | 3-0 on dwell, 2-1 against novelty | 15 seconds accumulated while visible **and** focused, paused on blur or hide, reset on a route change, once per thread per day. The labels are "Focused thread visits" and "Forums explored", never "read". Aesthete's novel-read rule was rejected because the activity data cannot reliably tell a change from the visit itself. |
| 8 | Triage | 2-0 (veteran silent) | Mark all read clearing Catch up counts as a check-in. A quiet day counts against fresh data. |
| 9 | Author-only mode (#4) | 3-0 that unknown is not clear | Unchecked threads block the check-in at that moment. A later ordinary refresh the same day can credit it. No badge-triggered requests. Aesthete's cross-day retro-credit was rejected as added state for little gain. |
| 10 | Day boundary | 1-1-1, so the owner decided | A TCT (UTC) day, `floor(now / 86400000)`, with no setting. This matches `formatAbsoluteTime`. Torn's own dailies are understood to reset at TCT midnight; that is not verified in this repo. The cost is accepted: for US players the day ends mid-evening. |
| 11 | Chip contents | 3-0 that the streak stays visible; 2-1 for showing an actual badge | Chair's synthesis: a cup drawn in the tier colour of the best earned badge, then the earned count, then the streak glyph and number. No 16px featured-badge glyph, which the aesthete showed is illegible. |
| 12 | Sibling PRs | 3-0 (native moved) | Do not wait. The PR is correct against current main and adds `isRecoveredValue` if it is absent. Whichever PR merges second reconciles. |
| 13 | Reset everything | Veteran, unopposed | Truly resets. No silent re-award on the next tick. |

## What moved

- **Native, point 12:** moved from "land the siblings first" to "do not wait". The house convention (branch off main, the second merger reconciles) satisfied repo-standards section 4.
- **Aesthete, point 9:** moved from crediting unchecked threads to a pending check-in. The chair kept only its same-day half.
- **Aesthete, point 7:** accepted the veteran's dwell-sampling bug (visibility checked only at second 15) and adopted accumulated focused time.
- **Aesthete, point 11:** moved from a cup-plus-count chip to keeping the streak visible.
- **Unmoved:** each seat's day boundary. That is why it went to the owner.

**Chair's note:** what would a fourth seat have looked for? Most likely accessibility of the earn toast for screen readers, and whether a badges-off user still accrues counters. Both are handed to the plan as explicit tasks, not as panel rulings.
